# 🍕 Tkinter Pizza Shop Simulator

A fun, beginner-friendly desktop GUI application built using Python's built-in **Tkinter** library. Users start with virtual cash and can purchase Small or Large pizzas, track their total pizza count, and earn extra money with a single click.

## ✨ Features
* **Starting Balance:** Begin with **\$10,000** in your virtual wallet.
* **Pizza Menu:**
  * **Buy Small Pizza (\$500):** Deducts \$500 and increases your total pizza count by 1.
  * **Buy Large Pizza (\$1,200):** Deducts \$1,200 and increases your total pizza count by 1.
* **Balance Validation:** Displays `"Not Enough Money!"` if you try to order a pizza without sufficient funds.
* **Earn Money:** Click **Earn Money +2000** anytime to add **+\$2,000** to your balance.
* **Live UI Counters:** Both your remaining balance and total pizzas bought update dynamically on screen.

## 🛠️ Technologies Used
* **Python 3**
* **Tkinter** (Standard Python GUI library — no external packages needed)

## 🚀 How to Run the Application

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd YOUR-REPO-NAME
   ```

3. **Run the Python script:**
   ```bash
   python main.py
   ```
   *(Make sure to replace `main.py` with your actual Python file name).*
